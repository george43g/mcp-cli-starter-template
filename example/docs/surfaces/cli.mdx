The CLI is `example` — a single bin that dispatches to subcommands. Every tool exposed via MCP is automatically also a subcommand here.

## Subcommands

```
example mcp [--http] [--port N] [--bind H]   run the MCP server
example tui                                   launch the Ink TUI
example doctor                                preflight checks
example repl                                  interactive REPL
example health                                one-shot health snapshot
example noop --input <text> [--upper]         demo tool invocation
```

## Global flags

| Flag | Description |
|------|-------------|
| `--json` | Machine-readable JSON output. |
| `-q, --quiet` | Suppress non-error output. |
| `-v, --verbose` | Debug-level info to stderr. |
| `--no-color` | Disable colors (also auto-disabled when stdout is not a TTY). |

## Env vars ↔ flags

Every recognized env var is also accepted as a CLI flag (see `@george43g/cli-kit/env-flag-binder`). Examples:

| Env | Flag | Purpose |
|-----|------|---------|
| `MCP_HTTP_TOKEN` | `--http-token` | Bearer token for HTTP transport |
| `MCP_LOG_DIR` | `--log-dir` | Override default `$TMPDIR/example/` |
| `MCP_DISABLE_NATIVE` | `--no-native` | Force TS fallback (skip Rust accel) |
| `MCP_TOOL_TIMEOUT_DEFAULT_MS` | `--tool-timeout-ms` | Per-tool default timeout |
| `EXAMPLE_DEV` | `--dev` | Enable dev-only tools (`get_logs`) |

## Run without installing

```bash
npx @george43g/example-mcp mcp
```

This downloads, runs, and exits. Use this when wiring the tool into an MCP host config.

## Install globally

```bash
npm  install -g @george43g/example-mcp
pnpm add  -g @george43g/example-mcp
```

After install, `example` is on your `$PATH`. All subcommands dispatch through that bin.

## Verify

```bash
example doctor
```

The `doctor` subcommand reports:
- Node version (must be ≥24)
- Optional native module presence
- Required env vars and their resolved values
- Log directory writability

## Connect from your editor

Add this to your MCP host's config file:

```json
{
  "mcpServers": {
    "example": {
      "command": "npx",
      "args": ["-y", "@george43g/example-mcp", "mcp"]
    }
  }
}
```

Config file paths:
- **Claude Desktop**: `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS), `%APPDATA%\Claude\claude_desktop_config.json` (Windows)
- **Claude Code**: `.mcp.json` at your project root
- **Cursor**: `.cursor/mcp.json` at your project root
- **OpenCode**: `opencode.json` at your project root
- **Warp**: Settings → AI → MCP Servers (UI)

## Source build

```bash
git clone https://github.com/george43g/mcp-cli-starter-template.git
cd mcp-cli-starter-template
mise install   # node + pnpm at pinned versions
pnpm install
pnpm build
pnpm verify
```

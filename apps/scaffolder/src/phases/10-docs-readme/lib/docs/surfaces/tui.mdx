## Keybindings

| Keys | Action |
|------|--------|
| `j` / `k`, Down / Up | Move down / up (with a count: `5j`) |
| `gg` / Home | Jump to top (double-press, as in vim) |
| `G` / End | Jump to bottom |
| `Ctrl+D` / `Ctrl+U` | Half-page down / up; the view and the cursor move together |
| `Ctrl+E` / `Ctrl+Y` | Scroll one line; the cursor stays put unless it would leave the screen |
| `Ctrl+F` / `Ctrl+B`, PageDown / PageUp | Page down / up |
| `d` | Toggle dev-stats panel |
| `q` / `Esc` | Quit |

Every binding is declared in one table, `src/tui/keymap.ts`: the shared vim
preset from `@george43g/keymap` plus the app's own keys, so a clash shows up in
`keymap.diagnostics`. The help bar renders from it, and so does the cheatsheet
output:

```bash
example-repo keys          # tab-separated: source, key, description, owner, file:line
example-repo --keys        # the same, as a flag, for cheatsheet collectors
example-repo --json keys   # the legend object; `pnpm build` also writes it to dist/keys.json
```

## Theme system

```bash
example-repo tui --theme powerline --accent '#1982FC'
```

Or via env:

```bash
MCP_TUI_THEME=powerline MCP_TUI_ACCENT='#1982FC' example-repo tui
```

The palette is derived from the accent (HSL math in `packages/tui-kit/src/theme/color.ts`). Glyph presets: `safe` (geometric/emoji, works in any terminal) and `powerline` (requires a Nerd Font).

## Architecture

Components live in `packages/tui-kit/src/components/`. Hooks (`useDevStats`, `useMouse`, `useVimKeys`) are reusable across apps. See [TUI design](/internals/tui-design) for deeper details.
